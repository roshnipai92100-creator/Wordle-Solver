This project is for a general Wordle, so some words might or might not be included in the version of Wordle you are using.

The New York Times Wordle has many words that aren't on the program's possible answer list, but it still includes over 98% of NYT's Wordle words.

If my solver is wrong or doesn't have the answer on the list, it is probably the version of Wordle you're using, not my program.
